# Тесты (интеграционные)

Запускают **настоящий backend** (`src/index.js`) с поддельным Telegram-ботом, который умеет имитировать сбои
(обрыв сети, 429, 403, зависание). Ничего не отправляется в реальный Telegram и не пишется в боевую БД.

```bash
# зависимости только для тестов — в package.json НЕ добавляются (чтобы не утяжелять деплой)
npm install --no-save pg-mem embedded-postgres

# терминал 1 — стенд на настоящем PostgreSQL (рекомендуется), либо без USE_REAL_PG=1 на pg-mem
USE_REAL_PG=1 node test/e2e-server.js

# терминал 2
node test/api-test.js          # регрессия: права, валидация, свадьбы, RSVP, /start (48 проверок)
node test/reliability-test.js  # надёжность доставки: сбои Telegram, дубли, падение, откат, нагрузка (43 проверки)
```

> **Важно:** проверка I2 (откат транзакции при сбое) надёжно проходит только на настоящем PostgreSQL (`USE_REAL_PG=1`).
> `pg-mem` не воспроизводит откат, поэтому на нём эта единственная проверка ожидаемо красная (42/43).
> Перед деплоем гоняйте на настоящем PostgreSQL: там 48/48 и 43/43.

Каждый прогон нужен на **чистом** стенде (перезапустите `e2e-server.js`): тесты рассчитывают на пустую БД.
